# Editable Creative Portfolio

Open `index.html` in a browser, or serve this folder with any static-server tool.

All portfolio content is centralized in `portfolio.config.js`:

- `name`, `location`, `role`, and `contact`
- hero and featured videos
- profile copy, roles, history, and languages
- work-card images and their URLs
- tool badges and external URLs

Each work card opens its configured URL in a new tab. To target a native app where supported, replace a card's `url` with an app deep link such as `instagram://...`.
